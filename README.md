# Soccer Training Registration Site

A cloud-based youth soccer training website where parents can review age-group programs and register their children.

## Features

- Responsive soccer academy landing page
- Programs for ages 5–15
- Parent and child registration form
- Cloudflare D1 database persistence
- Server-side validation
- Mobile-friendly layout
- Drizzle database migrations

## Technology

- React and TypeScript
- Next.js-compatible Vinext runtime
- Cloudflare Workers and D1
- Drizzle ORM
- Tailwind CSS

## Local setup

1. Install Node.js 22 or later.
2. Run `pnpm install`.
3. Run `pnpm dev`.
4. Open the local URL shown in the terminal.

The production website is currently managed through ChatGPT Sites.
